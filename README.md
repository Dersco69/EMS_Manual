# Dobrograd EMS — обновлённая версия

Это статический сайт без сборки. В отличие от предыдущей версии, материалы глав показаны непосредственно на странице, а не заменены ссылками на PDF. В шапке используется предоставленная эмблема Dobrograd Medical Center.

## Публикация
1. Распакуйте архив.
2. Загрузите всё содержимое архива в корень GitHub-репозитория: `index.html`, `styles.css`, `script.js`, `assets/`.
3. В GitHub откройте Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
4. Дождитесь окончания публикации.

Текст извлечён из предоставленного `Manual EMS.pdf`; номера страниц указаны для ориентира. PDF оставлен как необязательный исходник.
